# Layered Event Modelling (LEM)

**Semantic separation as a precondition for explicit causal analysis.**

Where one predicate (*integrity*, *failure*, *compromise*, *availability*) is applied across physical assemblies, executing systems, representations and organisational outcomes, the crossing between them disappears into a shared word. LEM keeps those layers apart: five structures (substrate, event abstraction, representation, epistemic access, normative standing), six edge types (causal, constitutive, classificatory, normative, representational, evidential), and a transition duration Δt that exists only on causal edges.
